# Images

Drop site photos here. Suggested files:

- `logo.svg` or `logo.png`: brand logo (replace `favicon.svg` references in the header and footer)
- `hero.jpg`: home page hero background, ~1920×1080 (see the TODO in `.hero` in `css/styles.css`)
- `og.jpg`: social share image, 1200×630 (add as `og:image` in each page's `<head>`)
- `gallery/`: before and after shots, landscape 4:3 works best

Compress photos before committing (e.g. https://squoosh.app). Aim for under 300 KB each.
